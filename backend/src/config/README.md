# Configuration Module

Environment variables and application configuration.

## Files (Planned)

| File | Purpose |
|------|---------|
| `env.js` | Load and validate environment variables |
| `database.js` | MongoDB connection config |
| `jwt.js` | JWT secret, expiry settings |
| `cloudinary.js` | Cloudinary API credentials |
| `google-maps.js` | Google Maps API key |
| `cors.js` | CORS allowed origins |
| `rate-limit.js` | Rate limiting thresholds |

## Environment Variables

See `backend/.env.example` for full list.
