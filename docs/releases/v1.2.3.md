# INFINITY FSM v1.2.3

## Fixed

- Windows startup CRT abort caused by `flutter_local_notifications_windows` when WinRT toast APIs failed.
- Unhandled WinRT/COM exceptions across the FFI boundary (`CreateToastNotifier`, show/cancel/schedule/history).
- Unpackaged Win32 toast identity: stable AUMID, activator CLSID, Start Menu shortcut, and LocalServer32 registration.
- Installer registry/shortcut AppUserModelID wiring for installed Release builds.
- Debug Start Menu shortcut no longer overwrites the installed `INFINITY.lnk` (uses `INFINITY (Development).lnk`).

## Windows notifications

- Local notifications remain **enabled**.
- When the Windows notification platform is available, plugin init succeeds and toasts can be shown.
- When the platform is unavailable, blocked, or misconfigured, init returns `false`, diagnostics are logged, and the app continues (login, sync, dashboard unaffected).

## Compatibility

- Target: Windows 10 / Windows 11 desktop (Flutter Windows runner manifest).
- Unpackaged Win32 (Inno Setup), not MSIX.
- Toast APIs require a working Windows notification platform (WPN). If WPN is disabled or broken for the user session, toasts cannot be shown, but the app must not crash.

## Verification

- `flutter analyze` (infos only; no new errors)
- Unit tests: Windows identity + fail-safe contracts + Android channels
- Windows Debug build + 25s live process check
- Windows Release build + 25s live process check
- Inno Setup compile: `INFINITY-Setup-1.2.3.exe`
- Live toast display: **not verified** on the development PC (notification platform returned unavailable for all AUMIDs)

## Install

Install `INFINITY-Setup-1.2.3.exe` (version **1.2.3+29**).
