# INFINITY FSM v1.2.4

Build: 30

## Fixed

- Windows Taskbar icon showed a blank/white document icon after v1.2.3 because the notification plugin wrote an **empty `IconUri`** registry value under the production AUMID.
- Debug and Production builds no longer share the same AUMID (`Com.TotalCom.Infinity` vs `Com.TotalCom.Infinity.Development`).
- Stale v1.2.3 `INFINITY (Development).lnk` Start Menu shortcut is removed on launch (it could point at a missing Debug executable and break shell icon resolution).
- Production Start Menu shortcut now sets an explicit icon from the installed Release executable (`SetIconLocation(exe, 0)`).
- Installer deletes any stale empty `IconUri` under the production AUMID during install.

## Windows notifications

- v1.2.3 FFI fail-safe behavior is **preserved**: init/show/cancel/schedule/history remain FFI-safe; WinRT failures do not abort the process; unavailable notifications remain non-fatal.
- Debug builds initialize the plugin with the Development AUMID; Release/installed builds use the production AUMID.

## Identity

- Production AUMID: `Com.TotalCom.Infinity`
- Development AUMID: `Com.TotalCom.Infinity.Development`
- Toast activator CLSID: `{04a35421-e8d4-4192-9ad2-abc142836211}`

## Verification

- `flutter analyze` on changed Dart files (no new errors)
- Unit tests: Windows identity + fail-safe contracts (9/9 passed)
- Windows Debug + Release builds succeeded
- Release `mobile.exe` contains embedded app icon (RT_GROUP_ICON)
- Registry: production AUMID has no empty `IconUri`
- Start Menu shortcut: production AUMID, valid Release target, explicit icon location
- Inno Setup compile: `INFINITY-Setup-1.2.4.exe`
- Debug/Release startup smoke: no CRT abort regression
- **Taskbar icon appearance was not visually verified** in this release (shell icon cache may require unpin/re-pin after upgrade)

## Install

Install `INFINITY-Setup-1.2.4.exe` (version **1.2.4+30**).

After upgrading from v1.2.3, if the Taskbar still shows a stale blank icon, unpin INFINITY from the Taskbar, run the app once from Start Menu, then pin again.
