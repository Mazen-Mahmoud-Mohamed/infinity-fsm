# INFINITY FSM v1.2.6

Build: 32

## Added

- Admin Official Holidays calendar (Gregorian, multi-date selection) under Settings.
- Company-scoped holiday persistence with Admin `settings:manage_holidays` permission.
- Backend holiday API for list, bulk replace, create, and delete.
- Mobile offline holiday sync/cache for technician overtime preview.

## Overtime

- Custom Admin holidays are full non-working days (same as Friday): all session overlap is overtime-eligible.
- Friday full-day overtime behavior is unchanged.
- Normal Saturday–Thursday still use 09:00–17:00 Africa/Cairo (before/after = overtime).
- Excel overtime export uses the same holiday-aware calculation.
- Dashboard overtime day-trends allocate multi-day sessions with holiday-aware rules.

## Tests

- Added automated backend and Flutter tests covering holiday overtime semantics, Excel vacation keys, API authorization, and offline calculator behavior.
